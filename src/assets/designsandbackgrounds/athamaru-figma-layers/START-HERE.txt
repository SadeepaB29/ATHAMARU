ATHAMARU • FIGMA LAYERS

Open the folder for your page. preview-assembled.jpg shows the actual
PNG layers stacked together. The numbered PNGs are the editable pieces.

ALIGN THE LAYERS
1. Create a frame with the original dimensions below.
2. Import the numbered PNGs as separate images inside the frame.
3. Give every PNG the same W and H as the frame. Set X = 0 and Y = 0
   relative to the frame for each one.
4. Stack the numbered files from lowest at the bottom to highest at
   the top. Keep the transparent padding around each image. That padding
   preserves each piece's original position.

The PNGs are lossless 2× exports in sRGB. The originals are SDR JPEGs.
Parts hidden by another piece were reconstructed from the surrounding
artwork. Pieces that run off the outside edge retain the source frame.
